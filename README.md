# Parus для Windows (установщик)

Настольный клиент для https://parus.onrender.com: значок в трее, окно, звонки, трансляция экрана
и **всплывающие плашки в углу экрана** при новых сообщениях (как в Telegram).
Работает в Windows 7 SP1, 8.1, 10 и 11, в 32-разрядной (ia32) и 64-разрядной (x64) версиях.

## Как получить Parus-Setup.exe (через GitHub, без установки чего-либо на ПК)
1. Создайте на GitHub **новый** репозиторий, например `parus-desktop` (не тот, что с сайтом).
2. Загрузите в него всё содержимое этой папки, включая скрытую папку `.github`
   (Add file → Upload files). Если папка `.github` не загрузилась — Add file → Create new file и в имени
   файла введите `.github/workflows/build.yml`, вставив содержимое из архива.
3. Откройте вкладку **Actions** → «Build Windows installer» → **Run workflow**.
4. Через 8–12 минут откройте завершившийся запуск → внизу **Artifacts → Parus-Setup**. Внутри:
   - `Parus-Setup.exe` — единый установщик, в котором вы выбираете 32 или 64 бита;
   - `Parus-Setup-x64.exe` и `Parus-Setup-ia32.exe` — отдельные установщики (запасной вариант).

## Сборка на своём компьютере с Windows
Установите Node.js 18+, запустите `build-local.bat`. Для единого установщика с выбором разрядности нужен NSIS
(https://nsis.sourceforge.io), иначе получите два отдельных установщика.

## Что происходит при установке
Приветствие → выбор 32/64 бита (по умолчанию подбирается автоматически) → обычный мастер установки (папка, ярлыки).
Установка без прав администратора, для текущего пользователя. При первом запуске приложение спросит,
запускать ли его вместе с Windows.

## Уведомления
Когда окно свёрнуто, закрыто в трей или не в фокусе, при новом сообщении в правом нижнем углу экрана
появляется плашка с аватаркой, именем и текстом; клик открывает нужный чат. Звонки показываются плашкой,
которая висит, пока вы не нажмёте. Звук сообщений играет сам сайт. Крестик на окне прячет Parus в трей;
выйти полностью — правой кнопкой по значку → «Выход».

> Важно: обновите и сайт на Render файлом `public/index.html` из нового `messenger.zip` — в нём подключены
> эти плашки. Дальше сайт обновляется сам, переустанавливать приложение не нужно (оно открывает ваш сайт).

## Заметки
- Установщик не подписан сертификатом, поэтому SmartScreen может показать «Неизвестный издатель»:
  «Подробнее» → «Выполнить в любом случае».
- Windows 7 должна быть с SP1 и актуальными обновлениями. Electron 22 — последняя версия, поддерживающая Windows 7.
- Другой адрес сайта: измените `SITE` в `main.js` (или переменную `PARUS_URL`) и пересоберите.
- Бесплатный Render засыпает: первый запуск может показывать экран «Сервер просыпается…» до минуты.
